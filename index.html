Jobwatch Offres

Comment ça se met à jour
  1. GitHub lance le script à 7h, 11h, 15h et 19h (heure de Paris) et enregistre les offres dans le dépôt.
  2. Cette page lit le fichier à chaque ouverture. « Actualiser » recharge les dernières offres.
  3. Ton suivi (à postuler, postulé, mails envoyés) est gardé dans ce navigateur, sur cet appareil.
